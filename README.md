# TRAXX

Aplicativo Android companheiro para organização de anotações e planejamento durante o jogo Oxide.

## Recursos
- Painel escuro em preto e azul
- Anotações de mapa, construção e inventário
- Guia pessoal de movimentação
- Aviso de segurança e integridade

Este aplicativo não modifica o jogo, não lê sua memória, não injeta código, não automatiza ações e não contorna sistemas antitrapaça.

## Gerar APK
O workflow **Build TRAXX APK** em GitHub Actions compila um APK de depuração. Após a execução, baixe o artefato `TRAXX-debug-apk`.
